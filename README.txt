JURNAL PENGELUARAN HARIAN

Fitur:
- Catat tanggal, kategori, keterangan, nominal, dan metode pembayaran.
- Total pengeluaran bulan terpilih.
- Total pengeluaran hari ini.
- Riwayat transaksi.
- Edit dan hapus transaksi.
- Export CSV.
- Data tersimpan lokal di perangkat.

CARA MEMASANG DI HP:
1. Agar dapat dipasang sebagai aplikasi (ikon di layar utama), folder ini perlu diunggah ke hosting HTTPS.
2. Buka alamat hosting tersebut melalui Chrome di Android.
3. Pilih menu Chrome > "Tambahkan ke layar utama" / "Install app".
4. Aplikasi dapat dibuka seperti aplikasi biasa.

CATATAN:
Versi ini tidak memerlukan akun dan data tidak dikirim ke server. Jika browser/data aplikasi dihapus, data lokal dapat ikut terhapus. Gunakan Export CSV secara berkala sebagai cadangan.
